## Workshop Description (Croatian, for public announcement)

### Kratki opis

Kako možete koristiti ChatGPT, Claude, Perplexity i druge AI alate da ubrzate svoje istraživanje, a da pritom zadržite akademsku čestitost? Kako pretvoriti nejasnu ideju u strukturiranu temu za seminarski ili diplomski rad? Kako provjeriti činjenice koje vam AI generira? Kako napisati kod za analizu podataka čak i ako niste programer?

Na ovoj radionici naučit ćete praktične vještine korištenja velikih jezičnih modela (LLM) u svim fazama ekonomskog istraživanja: od pregleda literature i formuliranja istraživačkog pitanja, preko analize podataka i pisanja koda, do strukturiranja i uređivanja teksta. Radionica je zamišljena kao hands-on iskustvo gdje ćete sami isprobati alate i tehnike na vlastitim primjerima.

### Što ćete naučiti

- Kako formulirati učinkovite upite (prompte) za različite istraživačke zadatke
- Kako koristiti AI za pregled literature i sintezu izvora
- Kako generirati, debugirati i dokumentirati kod za ekonomsku analizu (R/Python)
- Kako strukturirati akademski tekst uz pomoć AI alata
- Kako prepoznati i izbjeći zamke (halucinacije, plagijat, loša metodologija)
- Kako izgraditi reproducibilan istraživački workflow s AI alatima

### Pitanja na koja radionica odgovara

- Smije li se AI koristiti u akademskim radovima i kako to etički napraviti?
- Koji AI alat koristiti za koji zadatak?
- Kako verificirati informacije koje AI generira?
- Kako napisati prompt koji daje korisne rezultate?
- Kako integrirati AI u postojeći workflow pisanja seminarskog/diplomskog rada?
- Kako koristiti AI za kodiranje ako nisam programer?

## Workshop Structure

### Day 1: Foundations and Literature Workflow

**Duration:** 3.5 hours (16:00–19:30)

**Theme:** Understanding AI capabilities and using them for research discovery

#### Block 1.1: Introduction (45 min)

| Topic | Content |
|-------|---------|
| What are LLMs | Brief technical overview without jargon |
| AI landscape 2025 | Overview of major models (GPT-4, Claude, Gemini, Llama, Mistral) |
| Academic integrity | What is allowed, what is not, citation practices |
| Mental model | AI as research assistant, not replacement |

#### Block 1.2: Research Discovery with Perplexity (45 min)

| Topic | Content |
|-------|---------|
| Perplexity overview | Search + synthesis, citation tracking |
| Demo workflow | Finding literature on a sample economic topic |
| Hands-on exercise | Students search for sources on their own topics |
| Verification | Cross-checking AI-provided citations |

#### Break (15 min)

#### Block 1.3: Deep Research with Gemini (45 min)

| Topic | Content |
|-------|---------|
| Gemini Deep Research | Long-form research reports with sources |
| Demo workflow | Generating a literature review outline |
| Comparison | When to use Perplexity vs Gemini |
| Hands-on exercise | Students generate research summaries |

#### Block 1.4: Structuring Ideas with Claude (45 min)

| Topic | Content |
|-------|---------|
| Claude strengths | Reasoning, nuance, long context |
| Demo workflow | Turning messy notes into structured outline |
| Prompt engineering | Effective prompting for academic tasks |
| Hands-on exercise | Students structure their research questions |

#### Day 1 Wrap-up (15 min)

- Q&A
- Homework: Prepare a research question and 3 sources for Day 2

---

### Day 2: Coding and Writing Workflow

**Duration:** 3.5 hours (16:00–19:30)

**Theme:** Using AI for data analysis, code generation, and academic writing

#### Block 2.1: Coding with Claude Code (45 min)

| Topic | Content |
|-------|---------|
| Claude Code intro | Terminal-based agentic coding |
| Demo workflow | Loading data, cleaning, basic analysis in R |
| Best practices | How to describe what you want |
| Hands-on exercise | Students generate code for sample dataset |

#### Block 2.2: IDE Integration with GitHub Copilot + Positron (45 min)

| Topic | Content |
|-------|---------|
| Positron overview | Next-gen IDE for R (from Posit) |
| GitHub Copilot | Autocomplete and chat in IDE |
| Demo workflow | Writing an R script with Copilot assistance |
| Hands-on exercise | Students extend the script with new analysis |

#### Break (15 min)

#### Block 2.3: LLM Notebooks (45 min)

| Topic | Content |
|-------|---------|
| What are LLM notebooks | Interactive AI-assisted analysis environments |
| Demo workflow | Exploratory data analysis with AI guidance |
| Iteration | Refining analysis through conversation |
| Hands-on exercise | Students analyze a sample economic dataset |

#### Block 2.4: Writing and Editing with AI (45 min)

| Topic | Content |
|-------|---------|
| Writing assistance | Drafting, editing, feedback |
| Demo workflow | Improving a sample paragraph |
| Style consistency | Maintaining academic tone |
| Hands-on exercise | Students edit their own draft text |

#### Final Wrap-up (15 min)

- Complete workflow recap
- Resources and next steps
- Q&A
- Feedback collection

## Sample Datasets and Examples

### Demo Dataset Ideas

1. **Macroeconomic panel** - GDP, inflation, unemployment for EU countries (Eurostat)
2. **Survey microdata** - EU-SILC or similar household survey
3. **Time series** - Croatian economic indicators (HNB, DZS)
4. **Text data** - ECB monetary policy statements for sentiment analysis

### Sample Research Questions for Exercises

1. How does inflation affect household consumption in Croatia?
2. What factors explain youth unemployment variation across EU?
3. How do ECB communication patterns relate to market reactions?
4. What is the relationship between education spending and economic growth?

## AI Context Notes

This document is designed to be consumed by AI assistants to help with:

1. **Content generation** - AI can use this spec to generate consistent slides, exercises, and materials
2. **Translation** - All key content is provided in Croatian context
3. **Consistency** - Workshop structure is clearly defined for coherent material development
4. **Scope control** - Clear boundaries on what is and is not covered

### Key Constraints for AI Assistants

- Target audience: economics students with varying technical backgrounds
- Language: Croatian for all student-facing materials
- Tone: Practical, hands-on, avoiding unnecessary jargon
- Focus: Economic research applications, not general AI capabilities
- Ethics: Academic integrity must be emphasized throughout
- Tools: Focus on free or student-accessible versions

### Style Guidelines

- Use concrete examples from economics
- Prefer demonstrations over lectures
- Include verification/fact-checking in every workflow
- Emphasize AI as assistant, not replacement
- Address common fears (plagiarism, job loss) directly
