# Početak i pregled radionice

prerequisites.qmd objašnjava rad s jednim CSV-om i AI razgovorom.
workshop_overview.qmd povezuje osam tema. instructor.qmd opisuje
slijed razgovor, primjer i vlastiti pokušaj na cijelom skupu podataka.

corrections.md i compatibility.md čuvaju povijest metodoloških odluka
i tehničkih provjera. Aktualni web gradi se iz QMD izvora.
